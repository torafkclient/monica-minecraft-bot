🤖 Minecraft Discord Bot
Gelişmiş Minecraft Sunucu Yönetim Botu Discord ve Minecraft entegrasyonu ile sunucunuzu kolayca yönetin!

📋 Özellikler
🎮 Minecraft Yönetimi
/whitelist - Whitelist yönetimi
/ban - Oyuncu yasaklama
/kick - Oyuncu atma
/mc-duyuru - Minecraft sunucusuna duyuru gönderme

💬 Discord Yönetimi
/discord-duyuru - Discord sunucusuna duyuru gönderme
Özelleştirilebilir duyuru tipleri (Normal, Uyarı, Önemli)
Otomatik durum güncellemesi

⚙️ Bakım Modu
/bakim ac - Bakım modunu aktifleştirme

Whitelist kontrolü
